# Common errors mapping

> **Not documented** (same for every endpoint, or never surfaced over HTTP):
> - Authentication: `jwtDecodingError`, `invalidClaim`, `tokenVerificationFailed`, `missingHeader`, `badBearerToken`, `badDPoPToken`
> - Middleware-only: `tooManyRequestsError`
> - Infrastructure: `authenticationSaslFailed`, `htmlTemplateInterpolationError`, `pdfGenerationError`, `genericError`, `thirdPartyCallError`, `tokenGenerationError`, `missingRSAKey`, `missingKafkaMessageData`, `kafkaMessageProcessError`, `missingRequiredJWKClaim`, `jwksSigningKeyError`, `kafkaApplicationAuditingFailed`, `fallbackApplicationAuditingFailed`, `invalidSqsMessage`, `decodeSQSMessageError`, `pollingMaxRetriesExceeded`
>
> Processes covered: `eservice-template-process`.

## `invalidEserviceInterfaceFileDetected`

The interface file for the e-service template has invalid data.

| Process | BFF endpoint | When it happens | Reachable from the FE? | Steps to reproduce (UI) | Resolution steps |
| ------- | ------------ | --------------- | ---------------------- | ----------------------- | ---------------- |
| `eservice-template-process` | `POST /eservices/templates/:eServiceTemplateId/versions/:eServiceTemplateVersionId/documents` | BFF `verifyAndCreateDocument` converts an unrecognized interface kind/technology or a non-API parsing failure in `retrieveServerUrlsAPI` into `invalidInterfaceFileDetected`. | **CAN HAPPEN** — the shared file input accepts files without checking OpenAPI/WSDL structure; BFF validation runs before the process call. | **Data precondition:** admin/API user of tenant A; A has a draft REST template. <br>1. Go to `/erogazione/template-eservice`, open the draft with _Gestisci bozza_, then choose _Modifica bozza_. <br>2. Open _Specifiche tecniche_, select a valid-text OpenAPI file with a recognized version but invalid interface structure (for example, OpenAPI 3 without a `servers` array). <br>3. Click _Salva documento_. | 🟡 **Medium resolution**<br>1. Correct the OpenAPI/WSDL structure. <br>2. Upload the corrected interface. |
